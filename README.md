# Snake

Классическая игра «Змейка», реализованная на C++ с использованием графической библиотеки SFML.

Игрок управляет змейкой, собирает еду и набирает очки, стараясь не столкнуться со стенами или собственным телом. С каждым набранным очком скорость движения увеличивается.

## Возможности

- Графический интерфейс с текстурами и звуковыми эффектами.
- Случайная генерация еды на свободных клетках поля.
- Постепенное увеличение скорости игры.
- Подсчёт очков и сохранение лучшего результата в `highscore.txt`.
- Перезапуск после проигрыша.
- Логирование игровых событий в `game.log`.

## Структура проекта

- `app/main.cpp` — точка входа, обработка событий, управление состояниями игры и отрисовка.
- `include/` — заголовочные файлы классов и игровые настройки.
- `src/` — реализация игровой логики:
  - `game.cpp` — управление игровым процессом, проверка столкновений и подсчёт очков.
  - `snake.cpp` — движение, рост и управление змейкой.
  - `food.cpp` — генерация еды на игровом поле.
  - `logger.cpp` — запись игровых событий в лог.
- `asserts/` — текстуры, шрифт и звуковые файлы.
- `CMakeLists.txt` — конфигурация сборки.

## Сборка и запуск

Для сборки необходимы C++17, CMake 3.10+ и SFML 2.5+.

Установка зависимостей на Ubuntu:

```bash
sudo apt install g++ cmake libsfml-dev
```

Сборка проекта:

```bash
git clone https://github.com/harun00000/Snake.git
cd Snake
cmake -S . -B build
cmake --build build
```

Запуск из корневой директории проекта:

```bash
./build/snake
```

## Управление

| Клавиша | Действие |
|---|---|
| `W` | Движение вверх |
| `A` | Движение влево |
| `S` | Движение вниз |
| `D` | Движение вправо |
| `Space` | Начать игру |
| `R` | Перезапустить после проигрыша |

## Особенности реализации

Игровое поле состоит из сетки 20 × 20 клеток. Тело змейки хранится в `std::deque`, что позволяет добавлять новую голову и удалять хвост при движении.

Основные параметры игрового поля и скорости задаются в `include/config.hpp`. Игровая логика отделена от графического интерфейса и реализована в отдельных классах.
